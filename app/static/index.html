歡迎使用 DocuClarify

這是一個純本地儲存、零金鑰託管的文件智能檢索工具。支援混合檢索 (BM25 + 向量 RRF)、即時打字機串流輸出、Markdown 格式排版與多輪追問。

1 設定 AI 連線

點擊右上角「AI 連線設定」，填入您的 Base URL 與 API Key（支援 OpenAI、Ollama、DeepSeek、Groq 等）。

2 上傳文件並提問

拖曳 PDF、TXT 或 Markdown 檔案，系統自動切塊索引，回答時精準標註來源頁碼與段落。
